MODULE 1 — DÉCOUVERTE DE CAPCUT MOBILE

LEÇON 1 — Comprendre l’interface mobile

Quand vous ouvrez CapCut sur téléphone, vous voyez plusieurs zones importantes :

  • New Project : permet de créer un nouveau montage.
  • Timeline : zone principale où les vidéos sont placées.
  • Toolbar : contient les outils Text, Audio, Effects, Overlay.
  • Preview : écran permettant de voir le rendu final.

La timeline est le cœur du montage vidéo. Toutes les vidéos, musiques et textes y sont placés.

CONSEIL PROFESSIONNEL

Avant de commencer un montage :

- Organisez vos vidéos dans un dossier.
- Préparez votre musique.
- Préparez votre script.
- Supprimez les vidéos inutiles.

LEÇON 2 — Utiliser Split sur téléphone

L’outil Split permet de couper une vidéo en plusieurs parties.

Étapes :

1. Sélectionner le clip vidéo.
2. Déplacer le curseur blanc.
3. Cliquer sur “Split”.
4. Supprimer les parties inutiles.

Cette technique permet :

- d’accélérer le rythme,
- d’enlever les silences,
- de rendre les vidéos dynamiques.

TRAVAIL PRATIQUE

Créer une vidéo de 20 secondes avec :

- 10 cuts rapides
- suppression des silences
- transitions fluides

MODULE 2 — TEXTE ET SOUS-TITRES IA

LEÇON 1 — Ajouter du texte TikTok

Le texte est essentiel pour TikTok et Reels car beaucoup de personnes regardent les vidéos sans son.

Étapes :

1. Cliquer sur “Text”.
2. Cliquer sur “Add text”.
3. Écrire votre phrase.
4. Modifier couleur et police.
5. Ajouter animation.

Conseils :

- Utiliser des phrases courtes.
- Mettre les mots importants en couleur.
- Utiliser des animations rapides.

EXERCICE

Créer une intro TikTok avec :

- titre principal
- animation texte
- effet zoom

LEÇON 2 — Sous-titres automatiques IA

CapCut peut générer automatiquement les sous-titres grâce à l’intelligence artificielle.

Étapes :

1. Cliquer sur “Text”.
2. Cliquer sur “Auto Captions”.
3. Choisir la langue.
4. Générer les sous-titres.

Après génération :

- corriger les erreurs,
- modifier taille,
- ajouter animation,
- personnaliser couleurs.

MISSION

Créer une vidéo motivationnelle avec :

- voix off
- sous-titres automatiques
- musique émotionnelle
- zoom dynamique

MODULE 3 — AUDIO ET SOUND DESIGN

LEÇON 1 — Ajouter de la musique

La musique donne de l’émotion à la vidéo.

Pour ajouter une musique :

1. Cliquer sur “Audio”.
2. Choisir “Sounds”.
3. Importer ou sélectionner une musique.
4. Régler le volume.

Conseils :

- Ne pas mettre le volume trop fort.
- Synchroniser musique et transitions.
- Utiliser des musiques tendance TikTok.

EXERCICE

Créer un montage synchronisé avec les beats de la musique.

LEÇON 2 — Sound Design

Le sound design permet de rendre les vidéos plus immersives.

Effets populaires :

- Whoosh
- Impact
- Bass drop
- Transition sounds

Les monteurs professionnels utilisent toujours des effets sonores.

TRAVAIL FINAL

Créer une scène d’action avec :

- transitions rapides
- sound effects
- musique dynamique

MODULE 4 — COLOR GRADING MOBILE

LEÇON 1 — Correction des couleurs

Le color grading permet de transformer une vidéo normale en vidéo professionnelle.

Réglages importants :

- Brightness = luminosité
- Contrast = contraste
- Saturation = intensité couleurs
- Temperature = rendu chaud/froid

Pour un look cinéma :

- augmenter contraste,
- réduire légèrement saturation,
- ajouter température chaude.

EXERCICE

Transformer une vidéo classique en rendu Netflix.

MODULE 5 — TIKTOK / REELS / SHORTS

LEÇON 1 — Créer une vidéo virale

Une vidéo virale possède généralement :

- un hook rapide,
- du texte dynamique,
- des cuts rapides,
- une bonne musique,
- une forte rétention.

Le hook doit attirer l’attention dans les 3 premières secondes.
